แอดมินระบบ
ค้นหาชื่อร้าน หรือข้อความ

ปุ่มแชทลอย

  • วงกลม 56px สีดำ ไอคอนแชทสีเขียวมะนาว — สีเดียวกับปุ่มหลักของแอป
  • กดค้าง 0.2 วิ (หรือเริ่มลากเลย) = ลาก · แตะเฉยๆ = เปิดแชท
  • ปล่อยแล้วดูดเข้าขอบซ้าย/ขวาเอง ไม่บังเนื้อหา และจำตำแหน่งไว้
  • ปิดได้ 2 ทาง: ปุ่ม ✕ เล็กตอนชี้เมาส์ หรือลากลงวง ✕ ด้านล่าง
  • ปิดแล้วเรียกคืนได้จากเมนู "ติดต่อผู้ดูแล" (มือถือ = แถบล่าง "ติดต่อเรา")

หน้าต่างแชท

  • เด้งออกข้างปุ่ม ฝั่งเดียวกับที่ปุ่มอยู่ · มือถือเปิดเต็มจอ
  • ครั้งแรกมีหัวข้อให้แตะ: เข้าระบบไม่ได้ / ยอดไม่ตรง / ต่ออายุ ฯลฯ
  • แนบรูปหน้าจอได้ · แนบหน้าที่เปิดอยู่ + เวอร์ชันแอปให้อัตโนมัติ
  • บอกสถานะ "ส่งถึงผู้ดูแลแล้ว" → "อ่านแล้ว" ร้านไม่ต้องเดา
  • แอดมินตอบตอนแชทปิดอยู่ = ป้ายแดงบนปุ่ม + กล่องข้อความโผล่ข้างปุ่ม

หน้าแอดมิน

  • เมนูใหม่ "แชทลูกค้า" มีตัวเลขแดง = ข้อความที่ยังไม่อ่าน
  • รายการแชทเรียงล่าสุดก่อน กรอง รอตอบ / ปิดเรื่องแล้ว
  • หัวแชทบอกสถานะร้าน (ทดลอง/ใช้งาน) + ปุ่ม "เปิดดูร้าน" ใช้สิทธิ์เดิมที่มีอยู่
  • ข้อความสำเร็จรูปกดแล้วใส่ช่องพิมพ์ แก้ก่อนส่งได้
  • ของจริงใช้ตาราง support_threads + support_messages ผ่าน Supabase realtime ที่แอปใช้อยู่แล้ว

รอเจ้าของงานตัดสินใจ

  • ปิดปุ่มแล้ว ให้หายถาวร หรือกลับมาเองเมื่อเปิดแอปครั้งถัดไป?
  • นอกเวลาทำการ (20:00–09:00) จะขึ้นข้อความตอบอัตโนมัติไหม
  • สมาชิกในร้าน (ไม่ใช่เจ้าของ) แชทได้ด้วยไหม หรือเจ้าของคนเดียว
  • ต้องแจ้งเตือนแอดมินทาง LINE / อีเมลด้วยไหม ตอนไม่ได้เปิดหน้าแอดมิน

ชื่อร้านและข้อความทั้งหมดเป็นตัวอย่างสำหรับม็อกอัพ ไม่ใช่ข้อมูลลูกค้าจริง
